# Shriya Semwal | Interactive Portfolio 💼✨

Welcome to my personal portfolio codebase! This is a modern, highly interactive, and visually polished portfolio website built using **React**, **Vite**, **TypeScript**, and **Framer Motion**. It is fully responsive and features dynamic transitions, custom interactive cursor mechanics, and creative design layouts.

---

## 🚀 Key Features

* **🎨 Sleek Modern UI/UX**: Designed with a clean dark-mode aesthetic, vibrant gradients, premium typography, and harmonious colors.
* **✨ Smooth Animations**: Dynamic page transitions and micro-interactions powered by `framer-motion`.
* **🖱️ Custom Interactive Cursor**: A stylized custom cursor that reacts smoothly to user movement and interactive elements.
* **🏷️ Floating Stickers**: Playful, floating interactive graphic details that enrich the visual layout.
* **📱 Fully Responsive**: Automatically adjusts and scales beautifully across mobile, tablet, and desktop screens.
* **📄 Core Sections**:
  * **Hero**: A premium entrance screen with a strong visual presence.
  * **About**: Intro and background information.
  * **Skills**: Grid/visual representation of technologies and competencies.
  * **Experience**: Professional timeline with detailed descriptions.
  * **Education**: Academic history and credentials.
  * **Projects**: Interactive showcase of top projects.
  * **Contact**: Get-in-touch area with custom annotations.

---

## 🛠️ Tech Stack

* **Framework**: [React 18](https://react.dev/)
* **Build Tool**: [Vite](https://vitejs.dev/) (lightning-fast development and build server)
* **Language**: [TypeScript](https://www.typescriptlang.org/) (robust, type-safe development)
* **Animations**: [Framer Motion](https://www.framer.com/motion/) (fluid motion & physics-based animations)
* **Icons**: [Lucide React](https://lucide.dev/) (consistent, beautiful vector icons)
* **Styling**: Vanilla CSS (highly custom layout, properties, and grid systems)

## ⚙️ Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisite
Make sure you have [Node.js](https://nodejs.org/) installed (version 18+ recommended).

### 1. Clone the Repository
```bash
git clone https://github.com/ShriyaSemwal/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
Install all the required package dependencies:
```bash
npm install
```

### 3. Run Development Server
Start the local development server:
```bash
npm run dev
```
Open your browser and navigate to the address shown in the terminal (usually `http://localhost:5173`).

### 4. Build for Production
To generate a production-ready build of your site:
```bash
npm run build
```
This output is saved to the `dist/` directory, ready to be hosted on platforms like GitHub Pages, Vercel, Netlify, or Firebase.
